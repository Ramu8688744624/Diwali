# Happy Diwali, Vennela! — from Ramu 🪔

A colourful, static, mobile-responsive single-page Diwali greeting.

## Files
- `index.html` — page content with festive wishes and food delights gallery
- `style.css` — responsive festive styling, card hover effects, and animations
- `script.js` — festive sparkle particle interaction
- `assets/diwali-greeting-poster.png` — festive greeting artwork poster
- `assets/ice-cream.jpg` — ice cream photography
- `assets/chocolates.jpg` — gourmet chocolates photography
- `assets/kinder-joy.jpg` — Kinder Joy treats photography
- `assets/potato-chips.jpg` — crispy potato chips photography
- `assets/indian-sweets.jpg` — traditional Indian sweets photography
- `assets/pani-puri.jpg` — authentic pani puri photography

## Run
Open `index.html` in any modern web browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.

No backend, database, analytics, forms, or data collection are used. Google Fonts are optional; system fallbacks are included.
